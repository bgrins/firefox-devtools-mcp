Promotion code rules

One promotion code per order. Codes cannot be combined or stacked, and applying a second code at the basket replaces the first one.

Codes apply to the basket subtotal, before tax and before fees.

An expired code is refused at the basket and cannot be reinstated by an associate.

Brand exclusions are decided by the manufacturer and are not negotiable in store.

To use a code: open your basket, type the code into the promotion field, then choose Apply code. The basket recalculates before you continue to payment.
